# YOLOv8 Real-Time Object Detection

## Overview
Built a computer vision pipeline using YOLOv8 to detect objects in images and live webcam feeds.

## Features
- Processed COCO dataset validation set
- Logged 28,000+ detections with confidence scores
- Real-time webcam inference
- CSV logging for analysis

## Tech Stack
Python, YOLOv8, OpenCV, TensorFlow

## How to Run
pip install -r requirements.txt
python object_detection.py

## Results
- Avg confidence: >0.90
- Real-time performance achieved
